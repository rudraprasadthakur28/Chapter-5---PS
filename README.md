# Python Chapter 5 — Practice Set

This repository contains my solutions to the **Python Chapter 5 Practice Set**.

The exercises focus on dictionaries, sets, unique values, data types, dictionary keys and values, and understanding how Python handles different types of data.

## Questions Covered

### 1. Hindi-English Dictionary

Write a Python program to create a dictionary of Hindi words with their English translations. Provide the user with an option to look up a word.

### 2. Display Unique Numbers

Write a Python program to input **8 numbers** from the user and display all the unique numbers only once.

### 3. Integer and String Values in a Set

Check whether a set can contain both:

```python
18
```

and:

```python
"18"
```

as separate values.

### 4. Find the Length of a Set

Determine the length of the following set after performing the given operations:

```python
s = set()
s.add(20)
s.add(20.0)
s.add('20')
```

### 5. Identify the Type

Determine the type of:

```python
s = {}
```

### 6. Friends and Favorite Languages

Create an empty dictionary and allow **4 friends** to enter their favorite language as the value, using their names as keys. Assume that the names are unique.

### 7. Duplicate Friend Names

Determine what happens in Problem 6 if the names of **2 friends are the same**.

### 8. Same Favorite Language

Determine what happens in Problem 6 if the favorite languages of **2 friends are the same**.

### 9. List Inside a Set

Determine whether the values inside a list can be changed when that list is contained in a set:

```python
s = {8, 7, 12, "Harry", [1, 2]}
```
